DOKUMENTASI PROYEK

Struktur dan workflow website

Ringkasan teknis pembuatan website fan-page Snoopy untuk kebutuhan tugas informatika.

1 Struktur folder

website-snoopy/
├── index.html
├── profil.html
├── karier.html
├── komik.html
├── dokumentasi.html
├── css.css
└── assets/
    └── snoopy.jpg

2 Teknologi yang digunakan

  • HTML5 semantic: header, nav, main, section, article, footer.
  • CSS eksternal dengan Flexbox, Grid, variabel warna, dan responsive layout.
  • Aset gambar lokal disimpan terpisah dalam folder assets.
  • Navigasi memakai tautan ke file HTML yang terpisah.

3 Perintah Git dasar

git add .
git commit -m "Merapikan struktur website Snoopy"
git push origin main
