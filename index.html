Biografi Singkat

Snoopy diciptakan oleh kartunis Charles M. Schulz. Awalnya Snoopy bertingkah seperti anjing biasa, namun lambat laun berkembang menjadi karakter yang sangat imajinatif, pintar berjalan dengan dua kaki, dan memiliki kehidupan fantasi yang luar biasa.


Snoopy jarang berbicara dengan kata-kata terucap; pikiran dan perasaannya disampaikan melalui balon pikiran serta ekspresi pantomim yang lucu dan menggemaskan.

📖 Panduan Lengkap Dokumentasi Tugas Informatika

Gunakan panduan terstruktur di bawah ini untuk mengisi Buku Catatan Informatika kamu secara lengkap dan rapi!

1 Ide dan Tujuan Website

Ide Utama: Membuat website fan-page interaktif bertema karakter ikonik "Snoopy" dari komik Peanuts yang responsif, rapi, dan informatif.

Tujuan Proyek:

  • Mengaplikasikan struktur HTML dasar (semantic markup).
  • Menerapkan styling CSS Native (Flexbox, Grid, CSS Variables, dan Comic Theme).
  • Melatih workflow kontrol versi menggunakan Git dan repository GitHub.
  • Mempublikasikan website secara online menggunakan fitur GitHub Pages.

2 Struktur HTML & CSS Native

Website dibuat menggunakan beberapa file HTML, satu CSS eksternal, dan folder aset terpisah dengan kombinasi elemen sebagai berikut:

Komponen Elemen / Metode Fungsi
Header & Nav <header>, <nav>, <button> Menu navigasi tab interaktif dan tombol ubah tema.
Hero Section <section class="hero"> + gambar lokal Banner utama dengan ilustrasi visual Snoopy & deskripsi singkat.
Konten Utama <main>, <article>, CSS Grid Menampilkan biodata, alter-ego, hobi, dan fakta trivia.
Styling CSS Native (Variables, Flexbox, Keyframes) Desain gaya komik Peanuts (kuning, merah, outline tegas).

3 Langkah Membuat Repository & Menghubungkan Project

  1. Buka akun GitHub.com dan klik tombol New Repository.
  2. Beri nama repo: website-snoopy (Pilih Public, centang Add README file jika perlu).
  3. Buka aplikasi VS Code di komputer Anda.
  4. Buka folder proyek tempat file index.html disimpan.
  5. Buka Terminal di VS Code (Ctrl + ~) lalu jalankan perintah berikut: 
git init
git remote add origin https://github.com/USERNAME_KAMU/website-snoopy.git
git branch -M main

4 Proses Git Workflow (Add → Commit → Push)

Setiap ada perubahan kode pada file index.html, jalankan langkah berikut di terminal: 

# 1. Menambahkan seluruh perubahan file ke Staging Area
git add .

# 2. Menyimpan checkpoint/snapshot dengan pesan yang jelas
git commit -m "Menambahkan halaman profil dan panduan dokumentasi Snoopy"

# 3. Mengirimkan kode dari komputer lokal ke server GitHub
git push -u origin main

5 Penjelasan Push dan Pull (Penting!)

Istilah Arah Transfer Data Penjelasan Ringkas
Git PUSH 💻 Komputer → ☁️ GitHub Mengunggah (upload) commit terbaru dari komputer lokal ke repository GitHub online.
Git PULL ☁️ GitHub → 💻 Komputer Mengunduh (download) dan menggabungkan update terbaru dari repository GitHub ke komputer lokal.

6 Proses Mengaktifkan GitHub Pages

  1. Masuk ke repository website-snoopy di halaman web GitHub.
  2. Klik menu Settings (ikon roda gigi di bagian atas).
  3. Pada menu samping kiri, klik tab Pages.
  4. Pada bagian Build and deployment / Branch, ubah pilihan dari None menjadi main.
  5. Klik tombol Save.
  6. Tunggu 1–3 menit hingga muncul tautan publik seperti:
    https://USERNAME_KAMU.github.io/website-snoopy/

7 Proses Edit Kode & Re-Push

Jika ada perbaikan atau pembaruan isi website di VS Code:

  1. Edit file index.html di VS Code lalu simpan (Ctrl + S).
  2. Buka Terminal VS Code.
  3. Jalankan kombinasi perintah:
git add .
git commit -m "Update perbaikan styling dan penambahan trivia Snoopy"
git push origin main

Halaman GitHub Pages akan otomatis diperbarui dalam beberapa saat.

8 Kendala yang Ditemukan & Solusinya

2 3
No Kendala / Error Solusi / Cara Mengatasi
1 Error fatal: remote origin already exists Gunakan perintah git remote remove origin lalu tambahkan ulang link yang benar.
Tampilan GitHub Pages 404 Not Found Pastikan file utama bernama index.html (huruf kecil semua) dan berada di root folder.
Perubahan tidak muncul di GitHub Pages Lakukan Hard Refresh browser (Ctrl + F5) atau bersihkan cache browser.
